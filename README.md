# Кредитный калькулятор — PWA

Автономное приложение: после установки работает без интернета, шрифт системный, внешних запросов нет.

## Состав

```
index.html              приложение целиком (разметка, стили, расчёт)
manifest.webmanifest    имя, иконки, запуск в режиме standalone
sw.js                   service worker, кэширует всё для работы оффлайн
icons/                  180 / 192 / 512 px + maskable + favicon
```

## Важное ограничение

iOS не устанавливает PWA из локального файла. Нужен адрес по **HTTPS** — служебный worker без него не регистрируется (исключение только `localhost`). Поэтому сначала публикация, потом установка.

## Публикация — любой из вариантов

**GitHub Pages.** Загрузите содержимое папки в репозиторий, затем Settings → Pages → Deploy from branch → `main` / `root`. Адрес вида `https://<логин>.github.io/<репозиторий>/`.

**Netlify Drop** (быстрее всего, без аккаунта на старте): перетащите папку на `app.netlify.com/drop` — получите HTTPS-адрес сразу.

**Свой сервер / внутренний хостинг.** Положите папку в любой каталог статики под HTTPS. Все пути относительные, подкаталог не мешает.

## Установка на iPhone

1. Откройте адрес **в Safari** (в Chrome на iOS пункта установки нет).
2. Кнопка «Поделиться» → **«На экран "Домой"»** → «Добавить».
3. Запускайте с домашнего экрана: без адресной строки, с учётом безопасных зон, полностью оффлайн.

## Обновление версии

Правки в `index.html` подхватятся только после смены версии кэша: в `sw.js` замените `credit-calc-v1` на `v2`. Старый кэш удалится сам при активации. На устройстве обновление применяется после закрытия и повторного запуска приложения.
